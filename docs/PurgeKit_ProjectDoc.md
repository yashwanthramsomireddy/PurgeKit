## 1. Project Overview

PurgeKit is a free, open-source Windows temp and cache cleaner with a modern dark-themed GUI. It helps users reclaim disk space by cleaning temporary files, browser caches, app caches, system logs, 3rd party app caches, Adobe caches, and outdated installers — all in one place, with full user control.

### Mission
> Give every Windows user a fast, transparent, and completely free way to maintain their system — no subscription, no ads, no bloat.

### Key Principles
- **Free forever** — MIT licensed, no paid tiers
- **Transparent** — every deletion logged with technique used
- **Safe** — 3-technique force delete, whitelist support, dry run mode
- **Accessible** — 29 languages, compact/spacious UI, PIN lock

## 6. Force Delete — 3 Techniques

| Technique | Method | When Used |
|---|---|---|
| T1 | `robocopy /MIR` empty folder mirror | First attempt — fastest |
| T2 | `takeown` + `icacls` + force delete | If T1 fails |
| T3 | Register pending delete on next reboot | If T2 fails |

## 7. Software Updater

- Powered by **Microsoft winget** — free, official, no 3rd-party DB
- `winget upgrade` → detect outdated apps
- `winget show --id` → extract official vendor URL
- Download **directly from vendor's URL** with redirect following (GitHub → CDN)
- Real byte-level progress bar
- Opens installer for user to run — never silent execution
- Queue-based: downloads one app at a time
- Select All / Deselect All
- Saves to `Downloads\PurgeKit\Installers\<AppName>\`
- YAML files cleaned up automatically

## 12. Build Instructions

```bash
# Install dependencies
pip install customtkinter Pillow pystray winotify matplotlib pyinstaller

# Generate icon
python generate_icon.py   →  assets/icon.ico

# Build exe
build.bat   →  dist/PurgeKit.exe

# Build installer (Inno Setup)
# Open installer.iss → Compile   →  Output/Setup_PurgeKit_v3.6.exe
```

### Version Consistency — Always Update All 4
1. `APP_VERSION` in `PurgeKit.py`
2. `CURRENT_VERSION` in `core/updater.py`
3. `MyAppVersion` in `installer.iss`
4. Version badge in `README.md`
